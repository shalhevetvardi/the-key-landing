# the-key-landing - דף המפתח החי

הריפו הזה מגיש את the-key.aimprove.co.il (GitHub Pages מ-main). **מיזוג ל-main מעלה לאוויר מיד.**
הקובץ הזה יושב בתיקייה `.claude`, ולא בשורש, כדי שהאתר לא יגיש אותו לציבור (GitHub Pages מדלג על תיקייה שמתחילה בנקודה).

## ⚠️ לכל דף כאן יש עותק מקור ב-Storyteling, וכל שינוי נכנס לשניהם

| כאן | עותק המקור ב-Storyteling |
|---|---|
| `index.html` | `פרויקטים/אסטרטגיה-שיווקית-והמפתח/דף-המפתח.html` |
| `מסך-ההטבה.html` | `פרויקטים/אסטרטגיה-שיווקית-והמפתח/מסך-ההטבה.html` |

- **`index.html` והעותק שלו זהים בייט-לבייט.**
- **`מסך-ההטבה.html` והעותק שלו זהים חוץ מארבעה מקומות שמפנים לדף עצמו:** כאן `index.html`, שם `דף-המפתח.html`
  (שני הקבצים יושבים שם זה ליד זה). כל שוני אחר הוא פער.
- **למה זה חשוב:** מסך השיבוץ בדשבורד ההמלצות (sales-automation, `modules/testimonial_placements.py`, `KEY_MIRROR`)
  מסרב לפרסם לדף המפתח כשהעותק שונה מהדף החי, כדי לא לדרוס שינוי שלא הועתק. מ-24-10 עד 27-10-2026 שש בקשות כאן
  (#50-#55) שינו רק את הדף החי, ושיבוץ ההמלצות בדף המפתח היה חסום בלי שאיש ידע. תוקן ב-Storyteling #1649.
- תמונות ב-`assets/` הדשבורד מעתיק בעצמו. מי שמוסיף תמונה ביד מוסיף אותה גם ל-`assets/` שליד עותק המקור.

**הבדיקה, לפני שמבקשים משלהבת למזג בקשה כאן שמשנה דף:** בקשה ב-Storyteling עם אותו שינוי, ובבקשת האישור משפט
מיזוג לשתיהן. ואחרי המיזוג, מתוך עותק של הריפו הזה (שתי הפקודות לא כותבות כלום):

```bash
git fetch -q origin main && git -C ~/Storyteling fetch -q origin main && test "$(git -C ~/Storyteling rev-parse 'origin/main:פרויקטים/אסטרטגיה-שיווקית-והמפתח/דף-המפתח.html')" = "$(git rev-parse origin/main:index.html)" && echo "index: זהה" || echo "index: שונה"
```

```bash
diff <(git show 'origin/main:מסך-ההטבה.html' | sed "s/'index\\.html'/'דף-המפתח.html'/g; s/\"index\\.html/\"דף-המפתח.html/g") <(git -C ~/Storyteling show 'origin/main:פרויקטים/אסטרטגיה-שיווקית-והמפתח/מסך-ההטבה.html') && echo "מסך ההטבה: זהה"
```

התשובה הנכונה: `index: זהה` ו-`מסך ההטבה: זהה`. נמדד 27-10-2026: לפני #1649 שתיהן החזירו שונה.
⚠️ השנייה מחליפה רק `index.html` שבתוך מרכאות (שתי ההפניות ושני הקישורים). הערה אחת במסך ההטבה מזכירה
את `index.html` בלי מרכאות, והיא זהה בשני העותקים, ולכן לא מחליפים אותה.
